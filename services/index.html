Services

Every service running on the sd-ai.co.uk host, with the public URL, the container behind it, the route that publishes it and the operating notes. The facts are read from the live container register and the HTTP status is probed at build time, so these pages track what is actually deployed.

Wardenlive
Regulatory obligations turned into live, proactive alerting. A firm hears about a deadline before it becomes a breach.
warden.sd-ai.co.uk
Warden MLRlive
The sales-facing surface of the compliance platform, built around the one problem regulated firms care about: the obligation nobody is watching.
complsales.sd-ai.co.uk
Warden MLR Demolive
The compliance engine itself, opened. A guided five-stage tour of UK MLR 2017 running on seeded regulatory data — the same obligations the platform watches, with the clocks already running.
mlr.sd-ai.co.uk
GDPR Watchlive
Operational GDPR monitoring with the regulation organised into the five obligations that actually generate work, rather than its article structure.
gdpr.sd-ai.co.uk
Sentiment Analysislive
Every article scored three ways, with the agreement between models reported rather than hidden behind a single blended number.
sentimentanalysis.sd-ai.co.uk
Vector RAGlive
Long-term memory that survives the session and is reusable across runs — no per-token bill for every recall.
vector-rag.sd-ai.co.uk
Knowledge Graphlive
Structured context for agents that need relationships, not only embeddings — because similar text is not the same thing as the entity you asked about.
knowledgegraph.sd-ai.co.uk
Agent Harnesslive
A controlled way to use AI agents: several agents produce a result, a human reviews it before anything ships.
harness.sd-ai.co.uk
Loop Studiolive
The argument that the unit of AI work has changed from the prompt to the loop — demonstrated rather than asserted.
loop-demo.sd-ai.co.uk
Mini LLMlive
Small-model inference at the edge of the loop, fully logged and fully local — no inference bill, no data leaving the box.
mini-llm.sd-ai.co.uk
IndiaStocklive
AI-assisted equity research for Indian markets, combining the live sentiment signal with technical analysis over NSE listings.
indiastock.sd-ai.co.uk
Agents on Firelive
An autonomous trading firm operating £500,000 on UK equities, with every decision sealed on-chain so it can be checked afterwards.
markets.sd-ai.co.uk

Shared infrastructure

These back the services above and are not public services of their own: mlr-postgres, sentiment-postgres, puja-postgres, kafka + zookeeper, python-kg + python-kg-chroma, blockchain-provenance, ollama, traefik, cloudflared, and the observability stack (prometheus, grafana, tempo, otel-collector).

The product portfolio is at homelab.sd-ai.co.uk. The full host inventory is published from the container register, and the same material is maintained as a Confluence space (Server Services) for internal reference.
